**Title:** Neuzeit Drop + Studio One 7: free control-surface script (Launcher, mixer, scenes)

---

For anyone running a Neuzeit Drop with Studio One: I've put together an unofficial control-surface integration and made it free.

What it does:
- The 4×4 grid launches Launcher clips (the LEDs follow clip colour and play state)
- The 8 faders and mutes control 64 mixer channels using the Drop's layers, with feedback from S1
- The encoders and pushes are free for sends, plugin parameters, etc. via Control Link
- Snapshots launch Launcher scenes, so you can move through a live set from the snapshot matrix

Note: Studio One 7 can only be a clock master. It won't follow the Drop's Start/Stop, so start sets by launching a scene.

Files and setup: https://github.com/tiwadara/drop-studio-one

Not affiliated with Neuzeit or PreSonus. It's a community project. Questions welcome.
